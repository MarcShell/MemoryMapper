# MemoryMapper NICE-TO-HAVES:
- Entwicklt für Android und iOS, zwischendrin immer die plattformspezifischen Probleme behoben (Marc für Android, Uwe für iOS) ✓
- Koordinaten des Benutzers einfügen statt manuell schreiben (kann je nach Handy einige Sekunden dauern) ✓
- Bild mit der Kamera schießen ✓
- In dem List Screen kann man per klick auf Button zur Memory auf der Karte wechseln, animiert ✓
- Map Screen MemoryModal erweitert mit Button zum Wechseln zur Listenansicht mit betroffener Memory ausgeklappt für extra Infos ✓
- Map Screen erweitert mit Kompass, der erscheint beim Drehen, Drehung nach Norden bei Klick ✓
- Map Screen erweitert mit Anzeige des aktuellen Standorts und Button um diesem zu zentrieren ✓
- Map Screen Marker erweitert mit draggable Feature, welches die Memory updated sodass der neue Standort gespeichert wird ✓
- Darkmode / Lightmode mit Sun and Moon icons ✓
- Add Screen mit Update Screen erweitert, bei welchem die bereits angegeben Daten der betroffenen Memory vorgefüllt ist ✓
