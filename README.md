# Memory-Mapper
Eine React Native App für Menschen die gerne Reisen. Die App zeigt eine Weltkarte auf und erlaubt es dem User, Markierungen zu setzen und mit Informationen &amp; Bildern zu befüllen. Dadurch soll man einen Überblick darüber haben, welche Länder &amp; Sehenswürdigkeiten bereits besucht wurden.
